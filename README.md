# SA TTS Platform

An interactive audio platform for South African streamers on Kick.

## What It Does

SA TTS gives local streamers access to authentic South African text-to-speech voices, soundboard integration, and a clip vault for shareable moments. Viewers trigger TTS through chat commands, channel points, or donations. Streamers earn a share of every trigger.

## Status

Week 1: Landing page live. Dashboard, POPIA/FAQ, voice preview, and Kick OAuth sign-up in development.

## Tech Stack

- Frontend: HTML, CSS, JavaScript, React
- Backend: Python, FastAPI
- Database and Auth: Supabase
- Streaming Integration: Kick Public API
- TTS: Qfrency, Botlhale AI, and custom voice models
